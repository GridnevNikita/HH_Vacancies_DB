# 💼 HH Vacancy DB

Консольное приложение для загрузки и анализа вакансий с сайта [hh.ru](https://hh.ru) и сохранения их в **PostgreSQL**.  
Позволяет фильтровать вакансии, смотреть статистику и работать с данными через Python.

---

## 🚀 Функциональность
✅ Загрузка компаний и вакансий с hh.ru  
✅ Сохранение данных в PostgreSQL  
✅ Просмотр всех вакансий через консоль  
✅ Средняя зарплата и вакансии с зарплатой выше средней  
✅ Поиск вакансий по ключевому слову  
✅ Исключение дубликатов  

---

## 🧩 Структура проекта
```
hh_vacancy_db/
├── src/
│   ├── main.py           # Консольное меню для пользователя
│   ├── api_hh.py         # Работа с API hh.ru
│   ├── db_manager.py     # Работа с PostgreSQL
│   ├── db_create.py      # Создание базы и таблиц + загрузка данных через функцию load_companies_and_vacancies
├── .env                  # Настройки подключения к БД
├── pyproject.toml        # Зависимости (Poetry)
├── README.md             # Документация
```

---

## ⚙️ Настройки БД
Для работы проекта создайте файл `.env` в корне с параметрами подключения к базе:  

```
DB_NAME=your_db_name
DB_USER=your_user
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
```

---

## 💻 Запуск
1. Установить зависимости через Poetry:  

```
poetry install
```

2. Запустить консольный интерфейс и работать с данными:  

```
poetry run python src/main.py
```
